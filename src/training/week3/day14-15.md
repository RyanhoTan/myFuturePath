```tsx
students.map(student =>
  student.id === targetId
```

## 快记

- `students` = 整个数组；`student` = 当前遍历项
- 显示 → `map`
- 修改 → `map + 条件 + {...旧对象, 新值}`
- 删除 → `filter`
- 添加 → `[...旧数组, 新对象]`
- 统计 → 从现有 state 直接计算，通常不用再建 state
- input 的 `e.target.value` 是字符串，数字需要时用 `Number(...)`
- 同一组 Todo / Student → 一个数组 state，不是 map 出多个 state
